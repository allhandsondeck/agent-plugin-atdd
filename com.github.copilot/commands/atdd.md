description: Start ATDD from user stories and acceptance criteria using the shared atdd-workflow skill.
---

Read and follow the bundled [atdd-workflow skill](../../skills/atdd-workflow/SKILL.md)
before working on the developer's request. Resolve that link relative to
this command file, not relative to the developer's project. Load that
installed file in full.

Use the request and any story identifier or requirements location supplied
with this command as the input to the workflow. If no input was supplied,
ask which story or behaviour the developer wants to work on. Apply the
workflow in the developer's project, keeping its agreement checkpoints.

If the bundled skill cannot be located or read, explain the problem and stop
rather than proceeding without its instructions.
