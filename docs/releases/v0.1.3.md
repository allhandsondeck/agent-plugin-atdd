# ATDD Agent Plugin 0.1.3

Initial public early release of a shared Acceptance Test-Driven Development
workflow for coding agents.

## What it does

- Helps define a selected user story and acceptance criteria in your project.
- Proposes Given / When / Then scenarios and waits for agreement.
- Writes acceptance tests and checks that failures expose missing behaviour.
- Pauses for authorisation before implementation, then verifies the result.
- Reuses the project's test tools and saves requirements and testing context.

## Get started

Claude Code:

```sh
claude plugin marketplace add allhandsondeck/agent-plugin-atdd
claude plugin install atdd@atdd
```

In a fresh Claude Code session in your project:

```text
/atdd:atdd-workflow help me define and build a feature for exporting records to CSV.
```

Codex CLI:

```sh
codex plugin marketplace add allhandsondeck/agent-plugin-atdd
codex plugin add atdd@atdd
```

In a fresh Codex session in your project:

```text
$atdd-workflow help me define and build a feature for exporting records to CSV.
```

## Compatibility and validation

Claude Code and Codex installation and use are reported checked by the
maintainer. The repository includes a VS Code / Copilot slash command;
its complete workflow has not been verified. Copilot CLI, Cursor and other
clients are not claimed as tested.

Both Claude manifests pass strict packaging validation. Client versions
and live session evidence are not recorded in this release.

The plugin is instructions and packaging, with no runtime dependencies,
hooks, MCP servers or custom test framework. It guides an agent; it does
not technically enforce model compliance or guarantee correct software.
